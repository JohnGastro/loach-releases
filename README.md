# loach 配布版

loach のMac版（Apple Silicon、M1以降）の置き場所です。ソースコードはありません。

- 最新版: [Releases](https://github.com/JohnGastro/loach-releases/releases/latest) の `loach-Mac-arm64.dmg`
- 入れ方: DMGを開いて、loachを「アプリケーション」へドラッグ
- 更新: loachの設定「アプリの更新」に新しい版が出たら「ダウンロードして開く」。loachを終了（⌘Q）してから、同じようにドラッグして「置き換える」。メモとTODOは残ります
- 各リリースの `SHA256SUMS.txt` でファイルを確認できます。loachは更新時にこれと照合し、一致しないファイルは開きません

Appleの公証前の版です。初回起動でmacOSの確認が出たら「このまま開く」を選んでください。
